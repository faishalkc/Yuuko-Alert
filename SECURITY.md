# Security Policy

## Supported Versions

Yuuko Alert is a small personal project. Security fixes are generally considered for the latest version available on the `main` branch.

Older releases may not receive security updates. Please use the latest version when possible.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in Yuuko Alert, please report it privately and give the maintainer a reasonable opportunity to investigate and address it.

**Please do not disclose vulnerability details publicly in a GitHub issue, discussion, pull request, or other public forum before a fix or coordinated disclosure.**

Preferred reporting method:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability** to submit a private vulnerability report, if private vulnerability reporting is enabled for this repository.
3. Include enough information for the maintainer to understand and reproduce the issue.

If the private reporting option is unavailable, please contact the repository owner through their GitHub profile and request a private channel for reporting the issue. Avoid posting exploit details publicly.

## What to Include

When possible, include:

- A concise description of the suspected vulnerability and its potential impact.
- The affected version, commit, or file.
- Steps to reproduce the issue or a proof of concept that does not expose real user data.
- Any relevant logs or screenshots, after removing personal information, credentials, and other sensitive data.

Please do not include passwords, tokens, private data, or information belonging to other people in your report.

## Response and Disclosure

The maintainer will review the report and may ask for additional information. As this is a personal project, response and remediation times are not guaranteed.

Please allow time for investigation and a possible fix before making the vulnerability public. Coordinated disclosure is appreciated.

## Scope

This policy covers security issues in the Yuuko Alert project itself. Vulnerabilities in third-party libraries or services should also be reported to their respective maintainers.

Thank you for helping keep Yuuko Alert and its users safe.
