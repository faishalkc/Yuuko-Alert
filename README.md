# Yuuko Alert
Desktop application that displays a pop-up message with the cheerful "Selamat Pagi" greeting from the character Yuujo in Nichijou, accompanied by her signature voice. The app is designed to bring a fun and uplifting start to the day, helping users begin their morning with a positive vibe.
